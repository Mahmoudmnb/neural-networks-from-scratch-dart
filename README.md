# Neural Networks From Scratch in Dart

Educational Dart implementation of neural networks from scratch, including an
MLP and an Elman recurrent network with manual forward propagation,
backpropagation, training, evaluation, and weight persistence.

Runnable examples:

```sh
dart run bin/mlp_example.dart
dart run bin/elman_example.dart
```
